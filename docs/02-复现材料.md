## 单点复现（不走测试）

```bash
python3 - <<'EOF'
from nl2config.api import generate_config
r = generate_config("做个视频站", scenario="hallucinated_id")
print(r.status)   # → "ok"（幻觉 ID 的配置被当作合法结果直接返回）
print([c["componentId"] for p in r.config["pages"] for c in p["components"]])
```

## 结论

同一套 21 项测试在基线上产生 26 项失败（subTest 计入），覆盖问题报告全部失败模式；基线的 `api.py` 即"现状"：一次生成、裸输出直返、patch 盲目应用。修复后对照见 [06-回归记录.md](06-回归记录.md)。
